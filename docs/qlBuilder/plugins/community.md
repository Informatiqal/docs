# Community

This will be the place to list all community plugins available.

## Plugins list

### [Data Model Viewer](https://github.com/Informatiqal/qlbuilder-plugins/tree/main/data-model-viewer)

This plugin exports app's data model into a image (png). The plugin source its data directly from Qlik and its re-creating the model viewer.

### [Config editor](https://github.com/Informatiqal/qlbuilder-plugins/tree/main/config-edit)

Manage `.qlbuilder.yaml` file from `qlBuilder` itself by adding commands to add/remove/update environments and their properties.
